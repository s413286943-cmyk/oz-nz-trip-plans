# 澳新两次旅行 · 行程和自驾攻略

我们两次澳新旅行的行程和攻略：每天去哪、住哪、吃什么、花了多少。打开任意一天就能改成你自己的。

- **澳洲 2026**（7 月 28 日 – 8 月 13 日，两对夫妻，澳洲冬季）：16 天每天怎么走，整趟、每一段、每一天都附了我们的经验和花销；另有自驾攻略「4 次租车、6 天开车，我们踩过的坑」。
- **澳新 17 天**（南半球夏天，两人）：悉尼 3 晚 → 基督城取车自驾南岛到皇后镇 → 奥克兰。每天写满细节，可做可不做的标“可加”，二选一的写明“选这个会错过什么”；附吃什么、出发前清单和花销。

在线看：[https://oznz-trips.coze.site](https://oznz-trips.coze.site)（部署在 Coze）。

## 怎么用

- **在线改**：在澳新的“行程”页或 2026 的“改成你的”页点“开始改”，点开哪一天就能改标题、每一步、吃什么和提醒，也能加一步、删一步、上下移动。改动只存在你这台手机或电脑上，别人看不到。
- **带走**：“导出文字版”下载一份文字行程；“存成文件”把你的版本存下来，换设备后用“打开存的文件”接着改；也可以直接打印。
- **恢复成参考路线**：随时可以丢掉自己的修改，回到参考路线。
- **排你自己的路线**（`/plan`）：你定去哪几个地方、什么顺序、每处住几晚，可以从空白开始，也可以先载入我们的一条路线再改；还能加我们没去过的地方。站点按我们开过的路和在每个地方过过的日子排出每一天，并提醒哪天开车太久、哪里该给天气留一天、哪段路我们没走过。排好的方案在 `/mine`：可以加一天、删一天、调换顺序；`/mine/budget` 按你的人数、每处住几晚、开几天车估预算，每一行都能改；`/mine/prep` 按你的路线和出发日列出要订、要办的事，也能删掉不需要的、加自己的。
- **路线图和每天的光**：我们的新西兰行程顶部有路线示意图和每天开车多久的起伏；你自己的方案还有每天当地的日出日落和气温（往年平均，临近出发换成预报），出发后打开就是当天的「路上」：当地时间、离日落多久、接下来去哪、今晚住哪。
- **我们怎么排行程**（`/method`）：去哪儿都能用的做法。

## 换成你自己的行程

复制这个仓库，改 `data/` 里的 JSON 和 `public/` 里的图片就行：

| 文件 | 内容 |
|---|---|
| `data/nz.json`、`data/au2026.json` | 一次旅行：`trip`（标题、时间、封面）、`stages`（分段）、`days`（每天：`blocks` 时间线、`notes` 提醒、`drive` 开车路段）、`lodgings`、`todos`、`advice`、`dining` |
| `data/nz-costs.json` | 花销按类别和币种汇总 |
| `data/au2026-retro.json` | 2026 的经验：整趟、每一段、每一天 |
| `data/places.json` | 排路线用的地点库：每个地方（简介、建议住几晚、住处价格、我们在那里过的日子）、我们开过或飞过的路段和车程、两条预设路线、各国的花销基准、要订和要办的事 |
| `data/nz-overview.json` | 新西兰路线示意图：每站位置和一句话、大致走向、每天开车几小时 |
| `content/method.md` | 「我们怎么排行程」正文 |
| `content/au2026-guide.md` | 2026 自驾攻略正文（Markdown） |
| `public/nz/`、`public/au2026/` | 每天的配图（AI 生成的示意图）和攻略照片（实拍） |

时间线里 `period` 为“饮食”的那一步是当天的“早餐：…；午餐：…；晚餐：…”。

```bash
npm ci
npm run dev          # 本地开发
npm run build && npm start   # 生产模式，PORT 环境变量决定端口
npm test             # 编辑和导出的单测
npm run check:privacy  # 扫一遍有没有订单号、邮箱之类
npm run test:e2e     # 用本机 Chrome 跑一遍主要流程（需先 build）
```

Node 20.9 以上即可。没有数据库、登录或后端接口，任何能跑 Node 的地方都能部署。
