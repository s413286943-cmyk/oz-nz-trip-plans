# 澳新两次旅行 · 真实行程和自驾攻略

我们两次澳新旅行用的真实行程，去掉了订单号这类私人信息后公开出来。打开任意一天就能改成你自己的。

- **澳洲 2026**（7 月 28 日 – 8 月 13 日，两对夫妻，澳洲冬季）：走完回来写的自驾攻略，「4 次租车、6 天开车，我们踩过的坑」，含租车保险、三段自驾路线、住宿和全程花销；另附出发前排的每日行程。
- **澳新 2027**（2 月 1 日 – 17 日，两人）：悉尼 3 晚 → 基督城取车自驾南岛到皇后镇 → 奥克兰。每天写满细节，可做可不做的标“可加”，二选一的写明“选这个会错过什么”；附吃什么、出发前清单和出发前的花销。

在线看：**https://oznz-trips.coze.site**（部署在 Coze）。

## 怎么用

- **在线改**：在每日行程页点“开始改”，点开哪一天就能改标题、每一步、吃什么和提醒，也能加一步、删一步、上下移动。改动只存在你这台设备的浏览器里，别人看不到。
- **带走**：“导出文字版”下载 Markdown；“导出文件”下载 JSON，换设备后用“导入文件”接着改；也可以直接打印。
- **恢复原版**：随时可以丢掉自己的修改，回到原版。

## 换成你自己的行程

复制这个仓库，改 `data/` 里的 JSON 和 `public/` 里的图片就行：

| 文件 | 内容 |
|---|---|
| `data/nz2027.json`、`data/au2026.json` | 一次旅行：`trip`（标题、日期、封面）、`stages`（分段）、`days`（每天：`blocks` 时间线、`notes` 提醒、`drive` 开车路段）、`lodgings`、`todos`、`advice`、`dining` |
| `data/nz2027-costs.json` | 花销按类别和币种汇总 |
| `content/au2026-guide.md` | 2026 自驾攻略正文（Markdown） |
| `public/nz2027/`、`public/au2026/` | 每天的配图和攻略照片 |

时间线里 `period` 为“饮食”的那一步是当天的“早餐：…；午餐：…；晚餐：…”。

```bash
npm ci
npm run dev          # 本地开发
npm run build && npm start   # 生产模式，PORT 环境变量决定端口
npm test             # 编辑和导出的单测
npm run check:privacy  # 扫一遍有没有订单号、邮箱之类
npm run test:e2e     # 用本机 Chrome 跑一遍主要流程（需先 build）
```

Node 20.9 以上即可。没有数据库、登录或后端接口，任何能跑 Node 的地方都能部署。
